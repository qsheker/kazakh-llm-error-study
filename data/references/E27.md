## Required content or factual anchors

- Cryptographic hashing maps input to a fixed-size digest and is designed to resist practical reversal and collisions.
- Encryption transforms data with a key so authorized parties can decrypt it.
- Password storage should use a salted, costly password-hashing scheme; message confidentiality uses suitable encryption.
