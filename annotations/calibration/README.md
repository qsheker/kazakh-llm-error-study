# Dev calibration workbooks

The retained 12-response training and 20-response qualification files were
completed as a single team-assisted exercise. Their purpose is to test the
schema, offsets, rubric and validation scripts before the final run.

The provenance file in `outputs/calibration_team_assisted_20261115/` explicitly
states that the duplicated Rater 1/Rater 2 transport files contain joint
decisions. Agreement values of 1.0 are therefore technical consistency checks,
not evidence of independent human reliability or a passed inter-rater gate.

Calibration responses never enter the 240-response confirmatory analysis. The
public training and qualification manifests remain useful for proving that
read-only prompt, response, reference-card, word-count and finish-reason fields
were not changed.
